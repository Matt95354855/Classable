# Code Classcale

Ce répertoire accueillera uniquement le code propre à Classcale :

- adaptateurs de données crypto et actualités ;
- stratégies indépendantes ;
- détecteur de régime ;
- allocation et gestion du risque ;
- orchestration des backtests et du paper trading ;
- observabilité et journal d'audit.

Le moteur LEAN reste isolé dans `vendor/lean`.
